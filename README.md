# 🚀 CKB Learning Journey

Welcome to my **12-week learning journey into Nervos CKB**.

This repository documents my progress as I explore the Common Knowledge Base (CKB) blockchain, learn its architecture, build practical examples, and develop decentralized applications using Rust and the CKB development ecosystem.

Rather than only sharing completed projects, this repository captures the entire learning process—from fundamentals and experiments to challenges, solutions, and reflections.

---

## 🎯 Objectives

By the end of this journey, I aim to:

* Understand the architecture of Nervos CKB
* Master the Cell Model and the UTXO transaction model
* Learn how Lock Scripts and Type Scripts work
* Develop CKB smart contracts using Rust
* Explore the CKB SDKs, Capsule, Molecule, and supporting tools
* Build small applications that demonstrate real-world blockchain concepts
* Consistently document my learning and progress every week
